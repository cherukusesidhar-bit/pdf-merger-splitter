# PDF Merger & Splitter

A Python command-line utility to merge multiple PDF documents into one file or extract a selected page into a separate PDF.

## Features
- Merge two or more PDF files
- Extract a selected page from a PDF
- Checks file paths and page-number input
- Warns when encrypted PDFs are supplied
- Lets the user choose output filenames

## Requirements
- Python 3.8 or later
- pypdf

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

Follow the menu instructions to merge PDFs or extract a page.

## Technologies Used
- Python
- pypdf
